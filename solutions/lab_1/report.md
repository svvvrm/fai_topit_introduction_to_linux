Далее был написан bash скрипт для сбора диагностических данных о системе. Ниже представлен его код:

```bash
#!/bin/bash

# preparing environment
mkdir -p PASSPORT/log
mkdir -p PASSPORT/tmp

tmp_path=PASSPORT/tmp
report_path=PASSPORT/passport.txt
current_time=$(date) 

# logging
echo "$current_time: script started" >> PASSPORT/log/report.log

# collecting system information
echo $current_time > $tmp_path/date.tmp
hostname > $tmp_path/hostname.tmp
whoami > $tmp_path/user.tmp
pwd > $tmp_path/wd.tmp
ls -a> $tmp_path/files.tmp  

# creating report
echo "====== System Information ======" > $report_path
echo "" >> $report_path
echo "current time: $(cat $tmp_path/date.tmp)" >> $report_path
echo "host name: $(cat $tmp_path/hostname.tmp)" >> $report_path
echo "user: $(cat $tmp_path/user.tmp)" >> $report_path
echo "working directory: $(cat $tmp_path/wd.tmp)" >> $report_path
echo "working directory containment:" >> $report_path
echo $(cat $tmp_path/files.tmp) >> $report_path

# deleting temp files
find -name "*.tmp" -delete
```

После нескольких запусков файл `report.log` выглядит следующим образом:

```
Ср 16 сен 2026 10:37:52 +03: script started
Ср 30 сен 2026 09:34:00 +03: script started
```

а файл `passport.txt` так:

# Ответы на контрольные вопросы

## 1. Что произошло при запуске команды `chmod` чтобы сделать файл исполняемым?

Команда `chmod` изменила права доступа к файлу. В данном случае вся команды выглядела так:

```bash
chmod 700 script_passport.sh
```

Данная комманда дала владельцу файла права на чтение, запись и исполнение файла `script_passport.sh` и забрала все эти права у группы владельца и остальных пользователей.

## 2. Для каких процессорных архитектур есть готовые дистрибутивы Debian?

Официальные готовые сборки Debian выпускаются для широкого спектра архитектур:

- **amd64**: 64-битные процессоры ПК и серверов (Intel, AMD).
- **i386** — 32-битные процессоры ПК (старые Intel/AMD).
- **arm64** — 64-битные процессоры ARM.
- и т.д.

## 3. Разница между режимами поставки Debian и источники пакетов

| Режим поставки | Особенности                                                                                                                                                                                     | Когда удобно применять                                                                                                                         |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **Netinstall** | Минимальный образ (около 400-700 МБ), содержащий только сам установщик и базовую систему. Все остальные пакеты скачиваются во время установки из интернета.                                     | Когда есть стабильное и быстрое подключение к интернету, и нужно установить самую свежую версию пакетов без скачивания лишних гигабайт данных. |
| **Live-image** | Позволяет запустить полноценную операционную систему с графической оболочкой прямо с USB-флешки или DVD без установки на жесткий диск. При желании из этой же сессии можно запустить установку. | Для тестирования совместимости железа перед установкой, восстановления сломавшейся системы или работы на чужом ПК.                             |
| **Образа DVD** | Крупные образы (несколько гигабайт), которые содержат огромное количество предустановленного ПО и графических сред.                                                                             | При установке ОС на ПК в условиях отсутствия интернета или при очень медленном либо дорогом трафике.                                           |
| **Cloud**      | Специально подготовленные, максимально легковесные и настроенные образы дисков (в форматах qcow2, raw и др.) для виртуальных сред и облачных провайдеров.                                       | Для мгновенного развертывания новых серверов или виртуальных машин в облачных инфраструктурах.                                                 |
Пакеты берутся из официальных репозиториев Debian. Менеджер пакетов `apt` обращается к ним по сети для загрузки и обновления ПО. В случае использования полных образов DVD часть базовых пакетов может устанавливаться напрямую с самого носителя без подключения к сети.
